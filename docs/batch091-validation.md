## Tool contract

The YAML HTTP tools reuse `developmentRequest` / `developmentResponse`. Inputs: optional positive 32-bit objectId, validated WGS84 intersection bbox, geometry opt-in, `lang=en|tc` selecting the published name alias, limit 1–100 (default 10), offset 0–1,000,000. Queries order by OBJECTID. Continue with nextOffset using identical filters. HTTP timeout is 30 seconds, raw upstream cache TTL one hour; bilingual aliases share that cache. Outputs preserve source field codes, units, numeric strings, nulls and suppression values. Official catalogue dictionaries are required to interpret measure codes; no measure labels are invented. Historical figures are not current population estimates. Simplified Chinese names are not published by the selected fields and are explicitly rejected.

Pages cap records at 100 and serialized record bytes at 100 KB. Geometry requests use WGS84; projected Shape__Area/Shape__Length units remain unchanged. Complete polygons over 20 KB are explicitly omitted with access via meta.source, never truncated. Invalid/missing fields, wrong source field types, CRS errors, unclosed polygons, malformed JSON, ArcGIS error envelopes, HTTP/network/timeout failures are rejected with actionable errors. No raw SQL, arbitrary URL, layer or field input is exposed.
