## Contract

Nine YAML HTTP tools in `censtatd-population-geography` reuse the existing `developmentRequest` / `developmentResponse` transformers with individual official field contracts. Inputs: optional positive 32-bit objectId, validated WGS84 intersection bbox, geometry opt-in, `lang=en|tc`, limit 1–100 (default 10), offset 0–1,000,000. English and Traditional Chinese select published name aliases from the same bilingual provider body and share the one-hour upstream cache. Simplified Chinese is rejected because no such alias is published. Queries order by OBJECTID and use a 30-second timeout. No caller-supplied SQL, field name, layer or URL is exposed.

Outputs preserve source codes, numbers, numeric strings, nulls and suppression markers without coercion. Source periods remain present: DC_GHS includes 2016 observations; living-quarters layers identify 2023 and Q3 2023; density identifies 2024. These are not real-time estimates. Measure definitions and units require the official catalogue dictionary; no numeric rescaling is applied. Shape__Area/Shape__Length retain provider projected units, while returned geometry is WGS84.

Pages cap records at 100 and serialized record bytes at 100 KB, continuing through nextOffset with identical filters. Polygons over 20 KB are explicitly omitted with a link through meta.source; polygons are never truncated. Missing fields, wrong field types, invalid CRS, invalid/unclosed polygons, malformed JSON, ArcGIS error envelopes and HTTP/network/timeout failures produce errors. Empty valid pages remain distinct from provider failures. No UI or Next.js route code was changed; the installed local route-handler guide was inspected.
